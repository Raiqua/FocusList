# FocusList – Organize. Prioritize. Accomplish.

**FocusList** is a simple, responsive, and user-friendly productivity application designed to help users organize and manage their daily tasks efficiently. Users can quickly create tasks, assign priorities, mark them as completed, edit details, or delete them when they are no longer needed.

The app provides **High, Medium, and Low priority levels**, making it easy to identify important tasks at a glance. A powerful **search and filtering system** allows users to find tasks by title and filter them based on their completion status or priority.

A dedicated **statistics dashboard** displays the total number of tasks, completed tasks, and pending tasks, giving users a quick overview of their productivity and progress.

All tasks are automatically stored using **Local Storage**, ensuring that users don't lose their tasks even after refreshing or reopening the application.

With a clean interface, responsive design, intuitive controls, and smooth interactions, Task Manager provides a convenient way to **plan your day, stay organized, prioritize what matters, and keep track of your progress**—without requiring an account, server, or database.
